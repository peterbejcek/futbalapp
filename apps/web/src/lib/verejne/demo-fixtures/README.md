# Demo fixtures verejného webu

**Fiktívne** údaje (hráči, termíny, súperi, články) iba pre lokálny náhľad a vývoj.
Nikdy sa nezapisujú do databázy a neimportujú sa mimo `demo-source.ts`.
Mená hráčov sú vymyslené, portréty sú AI vizualizácia (assets/hero-blue-crest.png).
Po vystavení verejného API sa nahradia implementáciou `PublicDataSource` z API.
